# TabloDot - Öğrenci Yemekhane Uygulaması 🍽️

TabloDot, üniversite öğrencilerinin günlük ve haftalık yemekhane menülerini takip edebildiği, yemekleri puanlayarak geri bildirim verebildiği ve kişisel beslenme/alerjen durumlarını yönetebildiği React Native (Expo) tabanlı bir mobil uygulamadır.

## 🚀 Teknolojiler
*   **Frontend:** React Native (Expo)
*   **Veritabanı/Backend:** Supabase (Gelecek entegrasyon için planlanmıştır, şu an Mock Data kullanılmaktadır)
*   **Navigasyon:** React Navigation

## 📱 Ekranlar ve İşlevleri

*   **Giriş Ekranı:** Öğrencilerin okul numarası ve şifreleri ile sisteme güvenli giriş yapmasını sağlar.
*   **Bugün (Günün Menüsü):** Günün yemeğini görseliyle sunar. Kalori, makro besin değerleri (Protein, Yağ, Karbonhidrat) ve içerdiği alerjenler hakkında detaylı bilgi verir.
*   **Değerlendir (Yemek Puanlama):** Öğrencilerin menüye 1-5 arası yıldız verip, lezzet, sıcaklık ve porsiyon kriterlerini değerlendirebildiği ve yazılı yorum bırakabildiği geri bildirim ekranıdır.
*   **Haftalık (Haftalık Menü):** Seçili haftaya ait tüm günlerin yemeklerini ve toplam kalori miktarlarını liste halinde gösterir. Öğün planlamasını kolaylaştırır.
*   **Profil:** Öğrenci bilgilerinin yer aldığı, kişisel gıda hassasiyetlerinin (alerjenlerin) listeye eklenip çıkarılabildiği ve hesaptan çıkış yapılabilen yönetim panelidir.
